# Razonamiento Estratégico

Durante el proceso de exploración se evaluaron varios nombres:

* GuaraníSoft
* Kóga ERP
* Mbareté
* Yvy Software
* Ñande ERP

Después del análisis se concluyó que:

### GuaraníSoft

Fortalezas:

* Buena identidad corporativa.
* Comunica software y tecnología.
* Funciona bien como empresa desarrolladora.

Debilidad:

* Suena más a empresa que a producto.

---

### Kóga ERP

Fortalezas:

* Nombre corto.
* Fácil de recordar.
* Buena identidad paraguaya.

Debilidad:

* El significado puede inducir a conceptos agrícolas si se acompaña de símbolos incorrectos.

---

### Ñande ERP

Fortalezas:

* Alta carga emocional — "Ñande" = "nuestro" en guaraní.
* Identidad paraguaya inmediata.
* Fácil de recordar.
* Genera sentido de pertenencia.
* Escalable a múltiples productos.

Ejemplos:

* Ñande ERP
* Ñande CRM
* Ñande POS
* Ñande Nómina
* Ñande Inventario
* Ñande BI

Por estas razones se selecciona como marca principal.

## Concepto Visual — Ñ pixelada + Flor de Mburucuyá

### Diseño aprobado (v2.0 — 2026-06-16)

El logo combina tres elementos:
1. **Ñ pixelada** — símbolo construido por cuadritos modulares (gestión integrada)
2. **Flor de mburucuyá** — flor nacional del Paraguay como marca de agua sutil
3. **"ande ERP"** — texto al lado, sin repetir la Ñ (la Ñ es solo el símbolo)

El texto dice "ande ERP" (no "Ñande ERP") porque la Ñ ya está como símbolo.

## Guidelines de Uso del Logo

### Variantes obligatorias

| Variante | Uso |
|----------|-----|
| P1 — Compacto claro | Navbar fondo blanco, headers web |
| P2 — Compacto oscuro | Navbar fondo oscuro |
| P3 — Con eslogan | Login, PDFs, material comercial |
| P4 — Ícono puro | Favicon, app icon |
| P5 — Avatar circular | Perfil de redes sociales |

### Reglas de uso

* **Tamaño mínimo:** 24px en digital, 15mm en impreso
* **Padding mínimo:** 1x la altura del ícono a cada lado
* **Sobre fotos:** usar siempre versión avatar (P5) o con fondo sólido
* **No estirar ni distorsionar** — mantener proporciones siempre
* **No cambiar colores** — usar exclusivamente la paleta definida
* **No añadir sombras, brillos ni efectos** — el logo es plano
* **Modo claro:** usar morado `#5B2A86` + verde `#4A7C59`
* **Modo oscuro:** usar morado claro `#9B6DC4` + verde claro `#6FB07F`

| Color | HEX | RGB | Uso |
|-------|-----|-----|-----|

### Justificación

* **Morado** — creatividad, sabiduría, confianza. Psicológicamente llamativo sin ser agresivo.
* **Verde mburucuyá** — la flor nacional del Paraguay, aplicada como marca de agua en el logo. Crecimiento, calma.
* **Grises** — balance visual, legibilidad, modernidad.

# Esloganes

## Principal

> ERP paraguayo. Cumplimiento real. Soporte local.

### Por qué este eslogan

* **ERP paraguayo** — posicionamiento inmediato, diferenciación vs. extranjeros
* **Cumplimiento real** — no "cumplimiento" genérico, sino "real" (SIFEN v150, RG 49/14, Ley 6380)
* **Soporte local** — el dolor #1 de los ERPs extranjeros en Paraguay es el soporte

## Alternativas evaluadas

| Eslogan | Veredicto |
|---------|-----------|
| Gestión inteligente para crecer. | ❌ Genérico — podría ser cualquier ERP |
| El ERP hecho para empresas paraguayas. | ✅ Bueno, pero débil en diferenciador |
| Todo tu negocio en un solo lugar. | ❌ Cliché — todos los ERPs dicen esto |
| Control total para tu empresa. | ❌ Genérico |
| Simplificando la gestión empresarial. | ❌ Genérico |
| Facturación electrónica SIFEN completa, sin letras chicas. | ✅ Para campañas técnicas |
